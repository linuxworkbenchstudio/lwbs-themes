Colour customiser

Start from a released theme, change its colours, and download a KDE colour scheme and a Konsole colour scheme of your own. It runs in your browser: nothing is uploaded. It changes colours only; icons, the panel, the Plasma Style and the wallpapers stay as in the theme.

Use it. Colour scheme: put the file in ~/.local/share/color-schemes/, then pick it in System Settings › Colors & Themes › Colors. Konsole scheme: put the file in ~/.local/share/konsole/, then choose it in Konsole's profile settings › Appearance.
